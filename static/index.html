Decision-Support Workflow
  1. Discovery & CVE: Maps live network surface, exposed ports, and vulnerable software versions.
  2. Dijkstra (Initial): Exposes the attacker's path of least resistance through vulnerable hosts.
  3. Edmonds-Karp: Solves max-flow to extract the cheapest bottleneck cut (S-T partition).
  4. Severance: Simulates removing all min-cut links from the active network.
  5. Dijkstra (Verification): Proves target asset distance is now infinity.
